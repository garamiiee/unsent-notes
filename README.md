# 전하지 못한 진심

현실에서는 전하지 못했던 말을 안전한 디지털 공간에서 한 번 전해보는 인터랙티브 웹 서비스입니다.

> 실제 상대에게 메시지가 발송되지 않는 가상 전달 서비스입니다.

## 서비스 소개

삼켰던 한마디를 전달 방식과 상대에 맞춰 작성하고, 실제 앱을 닮은 화면과 전송 연출을 통해 마음을 꺼내봅니다. 전달이 끝나면 상대의 성격에 맞춘 가상 답장을 확인할 수 있습니다.

## 주요 기능

- 전달 방식 선택: 사내 메신저, 이메일, 공문, 보고서
- 상대 선택: 상사, 교수님, 팀플 빌런 팀원, 클라이언트, 전 연인, 친구
- 단계별 작성 흐름: 전달 방식 → 상대 → 메시지 작성 → 전달 연출 → 완료
- 테마별 작성 화면: 채팅, 이메일, 한글 문서, 공문 형식
- 가상 전달 애니메이션과 전달 완료 화면
- 상대별 사과·수긍 톤의 가상 답장
- 마음 보관함: 작성 기록을 브라우저에 저장하고 삭제
- 반응형 UI: 데스크톱과 모바일 화면에 맞는 레이아웃

## 사용 흐름

1. 전달 방식을 선택합니다.
2. 마음을 전하고 싶은 상대를 선택합니다.
3. 실제로 하지 못했던 말을 작성합니다.
4. 전달 버튼을 눌러 가상 전송 연출을 봅니다.
5. 전달 완료 후 원하면 가상 답장을 확인합니다.

## 기술 스택

- Next.js / React
- TypeScript
- Tailwind CSS
- React 기본 상태 관리 (`useState`)
- 브라우저 `localStorage`
- Vercel 배포

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

프로덕션 빌드는 다음 명령으로 확인할 수 있습니다.

```bash
npm run build
```

## 참고

- 작성 기록은 현재 사용 중인 브라우저의 로컬 저장소에만 남습니다.
- 브라우저 데이터 삭제, 시크릿 모드, 다른 기기에서는 기록이 유지되지 않습니다.
- 모든 전달과 답장은 가상으로만 진행되며 실제 메시지는 발송되지 않습니다.
